*Bee v2.8.2 is scheduled for release on **August 26th, 2026**. This is a security-related release, and all node operators are asked to upgrade as soon as the new version becomes available.*

## Bee v2.8.2 Is Scheduled for August 26th

Bee v2.8.2 is scheduled for release on **August 26th, 2026**. This announcement comes a week ahead of that date so operators can plan the upgrade.

{{< admonition warning >}}
**This is a security-related release.** All node operators are asked to upgrade to v2.8.2 as soon as the new version becomes available.
{{< /admonition >}}

## Why This Announcement Comes Without Details

Due to the nature of the release, the responsible course is to prioritize the security of the network and give operators time to move to the patched release before discussing the underlying issue and its details more openly.

This announcement therefore carries the release date and the upgrade request, and nothing more. Once v2.8.2 is out and the majority of nodes have upgraded, this post will be updated with a full account of what the release addresses.

Thank you for your cooperation.

## What Operators Can Do Now

The useful preparation is being ready to upgrade quickly on the day:

- Confirm which install method your node uses (package manager, Docker, or binary) and that you can run an upgrade without delay. The [upgrading Bee](https://docs.ethswarm.org/docs/bee/working-with-bee/upgrading-bee) page in the Bee documentation covers each path.
- Check the version your node is currently running, and note that the network's minimum supported version is **v2.8.0**. If you are still on **v2.6.0 or older**, upgrade to v2.8.0 first, as [described with the v2.8.1 release](https://blog.ethswarm.org/foundation/2026/bee-2-8-1-release/#bee-v260-support-removed), so you are not blocked on release day.
- Watch the [Bee releases page](https://github.com/ethersphere/bee/releases) on GitHub and the [#announcements](https://discord.com/channels/799027393297514537/816617743688007702) channel on the Swarm Discord for the release going live.

## Need Help?

If you're a node operator with questions about upgrading, join the [#node-operators](https://discord.gg/qs7QBKxrR4) channel on the Swarm Discord.
